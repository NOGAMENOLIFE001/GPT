# EXP-001 — First Training Pipeline & Tiny Language Model

## ЦЕЛЬ

Train a minimal transformer language model from scratch on CPU. Prove the full pipeline works:
DATA → TOKENIZER → MODEL → TRAINING → CHECKPOINT → INFERENCE → TEXT GENERATION

## ПОЧЕМУ

We must prove the core pipeline is functional before building on it. A model that cannot train or generate text invalidates all higher-level components.

## АРХИТЕКТУРА

### Model: Tiny Language Model (TLM)
```
Input Tokens
    ↓
Token Embedding (1024 × 128)
    ↓
Positional Encoding (RoPE, 128 dims)
    ↓
Transformer Block × 2:
  ├─ Multi-Head Attention (2 heads, 64 dims each)
  │   ├─ Q, K, V projections (128 → 64 × 3)
  │   ├─ Scaled dot-product attention (causal mask)
  │   ├─ Output projection (128 → 128)
  │   └─ Residual connection
  ├─ Layer Normalization
  ├─ Feed-Forward (128 → 256 → 128, GELU)
  │   └─ Residual connection
  └─ Layer Normalization
    ↓
Linear Head (128 → 1024, tied weights)
    ↓
Softmax
```

**Estimated parameters:** ~430K
**Estimated model size:** ~1.7 MB

### Training Pipeline
```
Config (YAML)
    ↓
Dataset → DataLoader (batched, shuffled)
    ↓
For each step:
  1. Forward pass (model tokens)
  2. Compute cross-entropy loss
  3. Backward pass (compute gradients)
  4. Gradient clipping (max_norm=1.0)
  5. Optimizer step (AdamW)
  6. LR scheduler step (cosine + warmup)
  7. Log metrics (loss, lr, perplexity)
  8. Evaluate (every 250 steps)
  9. Checkpoint (every 500 steps)
```

### Tokenizer: BPE
- Byte-level preprocessing
- Vocabulary: 1024 tokens
- Special tokens: `<pad>`, `<unk>`, `<bos>`, `<eos>`

## ЭКСПЕРИМЕНТ

Train TLM on D1 dataset for 5000 steps. Measure:
- Training loss curve (convergence)
- Validation loss (overfitting)
- Perplexity
- Training speed (tokens/sec)
- Memory usage (peak RSS)
- Checkpoint save/load functionality
- Text generation quality (qualitative)

## ГИПОТЕЗА

1. The tiny model will show monotonically decreasing training loss over 5000 steps
2. Validation loss will follow training loss but may begin overfitting after step 3000
3. Final perplexity will be < 15 (indicating the model learned basic token distribution)
4. Generated text will contain recognizable words from the training corpus
5. Peak RAM usage will be < 1.5 GB
6. Training will complete in < 2 hours on the Ryzen 5500U
