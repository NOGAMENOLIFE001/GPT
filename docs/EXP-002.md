# EXP-002 — Data Scaling & Early Stopping

## ЦЕЛЬ

Eliminate severe overfitting observed in EXP-001 by scaling training data from ~3.4K to ~100K tokens and adding early stopping.

## ПОЧЕМУ

EXP-001 showed catastrophic overfitting:
- Train loss: 6.94 → 0.22 (memorization)
- Val loss: 6.77 → 8.63 (divergence)
- Best val loss: 5.42 at step 1000 (far above target 2.5)
- Params/token ratio: 395K/3.4K = 116 (need ~100 tokens/param minimum)

## АРХИТЕКТУРА

Same model as EXP-001 (baseline):
- Tiny: 1024 vocab, 128 dim, 2 layers, 2 heads, 256 FFN, context 64
- ~395K parameters
- BPE tokenizer, RoPE, AdamW, cosine+warmup

Changes:
- Dataset: D1 expanded from 1 file (~3.4K tokens) → multiple files (~100K tokens)
- Early stopping: patience=500, monitor=val_loss, min_delta=0.001
- Max steps increased to 10000 (early stopping will halt earlier)

## ЭКСПЕРИМЕНТ

Train same architecture on 30x more data with early stopping. Compare:
- Val loss curve (should decrease then stabilize, not diverge)
- Best val loss (target < 2.5)
- Best perplexity (target < 12)
- Step where early stopping triggers
- Generation quality

## ГИПОТЕЗА

With 100K tokens (~250 tokens/param):
1. Val loss will decrease monotonically or plateau (not diverge)
2. Best val loss < 2.5 achievable
3. Perplexity < 12 achievable
4. Early stopping will trigger before 5000 steps
5. Generated text will show coherent patterns from training data
